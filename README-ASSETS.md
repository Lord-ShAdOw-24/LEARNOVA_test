# Learnova — pack badges (tout à la racine)

Déposez **tous ces fichiers à la racine du dépôt GitHub**. Pas de sous-dossiers.

## Badges

| Fichier | Usage |
|---|---|
| `learnova-verified.png` | Badge bleu de vérification plateforme. À côté du nom (compte / prof certifié). |
| `learnova-scan.png` | Alerte SCAN (scam / signalements). S’affiche sur le **groupe** en attendant la revue. Pas un ban. |
| `learnova-freeze.png` | Gel temporaire (flocon). L’entité reste visible, activités coupées. |
| `learnova-ban.png` | Ban définitif. Groupe / compte inaccessible. |
| `learnova-shield.png` | Bouclier de niveau de dépenses. Le **chiffre** (0, 1, 2…) s’écrit **au centre**. |
| `learnova-flame-sm.png` | Flamme niveau 1 — 7 jours d’affilée. Petite, à côté du nom. |
| `learnova-flame-md.png` | Flamme niveau 2 — 21 jours. Taille moyenne (visuel fourni). |
| `learnova-flame-lg.png` | Flamme niveau 3 — 45 jours. Grande + glow. |

Un jour compte si l’élève : quiz, ouvre un papier, rejoint un cours, télécharge, ou entre en compétition.

Priorité sur un nom : **ban > gel > SCAN > vérifié**, puis la flamme (jamais sur un ban / gel).

## Bouclier — seuils L-Credits dépensés

0 = 0 · 1 = 50 · 2 = 150 · 3 = 400 · 4 = 1000 · 5 = 2500

Le numéro s’affiche dans le bouclier, sur le profil, au bord du cercle photo.
